# Scale help

Pick a key and a scale at the top of the page. Buddy Harmony draws every note of that scale across the fretboard.

Turn on **Show triads** to highlight the root, third, and fifth of the scale — useful for seeing where the underlying chord tones sit within the full scale shape.

Use the gear icon to change guitar type, tuning, or how the fretboard is drawn. Use the print icon to print the diagram shown.
