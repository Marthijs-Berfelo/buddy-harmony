# Chord help

Pick a key and a chord name at the top of the page. Buddy Harmony shows every fretboard position it knows for that chord — each diagram is a different way to play the same chord further up or down the neck.

### Other tools

- Gear icon — change guitar type, tuning, or how the fretboard is drawn (orientation, left-handed mirroring, fret number style)
- Print icon — print the diagrams shown
